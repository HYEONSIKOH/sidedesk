# 프로젝트 소개

이름은 SideDesk 다.

## 한 줄 설명

컴퓨터 옆에 세워 둔 스마트폰을 컴퓨터 상태 화면 겸 조작판으로 쓰는 프로그램이다.

## 무엇을 하나

| 화면 | 내용 |
|---|---|
| 홈 | 큰 시계, 날짜, 날씨, 연결 상태 |
| AI 세션 | 컴퓨터에서 돌고 있는 AI 코딩 작업의 진행 상태. 끝나거나 답을 기다리면 폰이 알려 준다 |
| 성능 | CPU, GPU, 메모리, 디스크, 네트워크 |
| 프로세스 | 많이 쓰는 프로그램 목록. 폰에서 바로 종료 |
| 단축키 | 폰의 버튼을 눌러 컴퓨터의 앱과 명령 실행 |
| 음악 | 컴퓨터에서 재생 중인 음악 보기, 재생과 볼륨 조작 |

- 한 화면이 크게 보이고 나머지는 옆에 작은 칸으로 계속 움직인다. 작은 칸을 누르면 커진다.
- 화면은 저절로 바뀌지 않는다.
- 밝은 테마와 어두운 테마가 있다.
- 쓰지 않을 때는 검은 화면에 시계만 어둡게 띄운다.

## 누가 쓰나

컴퓨터로 오래 일하는 사람, 특히 AI 코딩 도구를 여러 개 돌리는 개발자. 안 쓰는 폰도 다시 쓸 수 있다.

## 어떻게 연결하나

USB 케이블이나 블루투스로 컴퓨터와 폰을 바로 잇는다. 중간 서버와 회원 가입이 없다. 처음 한 번 짝을 맺고, 이후 통신은 암호화한다.

## 무엇으로 만드나

| 부분 | 언어 |
|---|---|
| 컴퓨터 프로그램(맥, 윈도우) | Rust |
| 안드로이드 앱 | Kotlin |
| iOS 앱 | Swift |

## 중요하게 보는 것

- 가볍게: 컴퓨터 메모리와 CPU 를 적게 쓴다
- 편안하게: 오래 봐도 눈이 피로하지 않은 색과 큰 글자
- 안전하게: 폰은 미리 등록한 명령만 실행할 수 있다

## 지금 상태

같은 컨셉의 시제품을 맥과 안드로이드 접는 폰에서 쓰고 있다. 코드를 전부 새로 만드는 중이다. iOS 와 윈도우는 계획 단계다.
