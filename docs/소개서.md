# SideDesk 소개서

컴퓨터 옆에 세워 둔 스마트폰을 상태 화면 겸 조작판으로 쓰는 프로그램입니다.

> 개발 초기입니다. 아래 기능은 계획이며 아직 쓸 수 있는 버전이 없습니다.

## 왜 만드나

- AI 코딩 작업을 여러 개 돌리면 어느 것이 끝났고 어느 것이 답을 기다리는지 창을 옮겨 다니며 확인해야 합니다.
- 컴퓨터 상태를 보거나 음악을 바꾸려면 하던 일을 멈추고 창을 바꿔야 합니다.
- 책상 위의 스마트폰 화면은 대부분 꺼져 있습니다. 안 쓰는 폰이 서랍에 있기도 합니다.

SideDesk는 이 정보를 폰 화면으로 옮겨, 하던 창을 그대로 두고 옆을 보기만 하면 되게 합니다.

## 무엇을 보여 주나

| 화면 | 볼 수 있는 것 | 할 수 있는 것 |
|---|---|---|
| 홈 | 시계, 날짜, 날씨, 연결 상태 | 시계 모양과 테마 바꾸기 |
| AI 세션 | 작업별 진행 상태 | 끝남과 답변 대기 알림 받기 |
| 성능 | CPU, GPU, 메모리, 디스크, 네트워크 | |
| 프로세스 | 많이 쓰는 프로그램 | 종료 |
| 단축키 | 등록한 버튼 | 앱 열기, 명령 실행 |
| 음악 | 재생 중인 곡 | 재생, 이전과 다음 곡, 볼륨 |

## 화면 원칙

- 하나는 크게, 나머지는 작은 칸으로 함께 보입니다. 작은 칸을 누르면 커집니다.
- 보고 있는 화면은 저절로 다른 화면으로 바뀌지 않습니다.
- 밝은 테마와 어두운 테마가 있고 직접 고릅니다.
- 오래 쓰지 않으면 검은 화면에 시계만 어둡게 남깁니다.

## 어떻게 동작하나

```
컴퓨터 (macOS, Windows)  ── USB 또는 블루투스 ──  스마트폰 (Android, iOS)
  정보를 모으고                                     화면을 보여 주고
  명령을 실행                                       버튼을 누름
```

- 컴퓨터와 폰을 직접 잇습니다. 회원 가입과 중간 서버가 없습니다.
- 처음 한 번 짝을 맺고, 이후 통신은 암호화합니다.
- 폰에 보이는 정보만 모읍니다. 폰이 연결돼 있지 않으면 수집을 멈춥니다.
- 폰은 미리 등록한 명령만 실행할 수 있습니다.

## 무엇으로 만드나

| 부분 | 언어 |
|---|---|
| 컴퓨터 프로그램, 통신과 암호화 공용 코어 | Rust |
| 안드로이드 앱 | Kotlin |
| iOS 앱 | Swift |

## 개발 순서

1. 공용 코어, 짝 맺기, USB 연결
2. macOS 정보 수집과 명령 실행
3. 안드로이드 화면
4. 블루투스 연결 (macOS)
5. Windows 지원
6. iOS 앱
7. 배포

현재는 프로젝트 틀만 있고 1단계를 시작하기 전입니다. Windows의 블루투스 연결 방식은 아직 정하지 못했습니다.
