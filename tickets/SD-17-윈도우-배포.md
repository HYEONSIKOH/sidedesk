# SD-17 [Desktop] 윈도우 배포 zip

| 종류 | 상태 | 우선순위 | 라벨 |
|---|---|---|---|
| 작업 | 진행 중 | 높음 | Desktop, CI |

## 목적

SD-15 에서 미룬 윈도우 배포 파일. 맥과 같이 홈 경로를 지우고 비밀값 검사를 통과한 zip 만 Actions 산출물로 남긴다. 공개는 사람이 정한다.

## 범위

- `SideDesk-<버전>-windows-x64.zip`: `sidedesk.exe`(설정 창, 콘솔 창 없음), `sidedesk-cli.exe`(pair, run), `README.txt`(내용은 한글, 이름은 압축 도구에서 깨지지 않게 영문). PDB 는 넣지 않는다
- 빌드할 때 사용자 폴더, Rust 설치 폴더, 저장소 경로를 컴파일러 경로 바꾸기로 지운다. PDB 경로는 실행 파일 안에 파일 이름만 남긴다(`/PDBALTPATH:%_PDB%`)
- 비밀값 검사: zip 을 `check_secrets.py --artifact` 로, 빌드한 곳 경로는 역슬래시와 빗금 두 꼴로 `--forbid`
- `release.yml` 에 윈도우 작업. ci.yml 의 개발용 윈도우 산출물은 그대로 둔다(개발 확인용)
- README 의 윈도우 설치 줄(준비 중 → 설치 안내, SmartScreen)
- 서명 없음(의문점 45)

## 끝난 기준

- 이 브랜치에서 release.yml 을 수동으로 돌려 윈도우 zip 이 산출물로 나오고 검사를 통과한다
- zip 안 두 실행 파일에 홈 경로와 러너 경로가 없다
