# SD-5 [공통] 블루투스 연결

| 종류 | 상태 | 우선순위 | 라벨 |
|---|---|---|---|
| 작업 | 진행 중 | 높음 | Core, Desktop, Android |

## 목적

케이블을 빼도 맥과 안드로이드 기기가 블루투스 LE 로 이어져 있게 한다. 다시 꽂으면 USB 로 돌아간다. 옮기는 동안 기기 화면은 마지막 값을 그대로 보인다.

## 범위

- 기기가 블루투스 LE 로 자기를 알린다. 맥은 등록된 기기만 골라 붙는다
- 연결은 BLE L2CAP 한 줄로 하고, 그 위에 SD-2 의 암호화 연결을 그대로 쓴다
- USB 가 붙어 있으면 USB 를 쓰고, 빼면 블루투스로, 다시 꽂으면 USB 로 옮긴다
- 설정 창의 연결 방식 칸에 "블루투스"가 나온다
- 맥 블루투스가 꺼져 있거나 권한이 없으면 설정 창에 이유가 나온다

하지 않는 것
- 윈도우 블루투스 (설계 4절: 쓸 수 있는 공식 방법을 아직 못 찾음). 윈도우는 USB 만 쓰고 컴파일만 통과시킨다
- 블루투스로 처음 등록하기. 등록은 지금처럼 USB 로만 한다
- iOS (설계 순서 6단계)
- 와이파이

## 조치

- 기기는 앱이 앞에 있는 동안 블루투스 LE 로 알리고, L2CAP 채널을 열어 둔다
- 맥은 CoreBluetooth 로 찾고 붙는다. 맥 프로그램을 `SideDesk.app` 로 묶어 블루투스 권한을 받는다
- 같은 기기에 USB 와 블루투스가 동시에 붙지 않게, 기기 키 기준으로 한쪽만 붙인다

## 끝난 기준

- [x] 등록된 안드로이드 기기를 USB 로 붙인 뒤 케이블을 빼면 10초 안에 블루투스로 다시 붙는다 (A71, 1.5초)
- [x] 블루투스로 붙은 상태에서 케이블을 꽂으면 10초 안에 USB 로 옮긴다 (USB 디버깅 허용 직후 바로)
- [x] 등록 안 된 기기에는 블루투스로 붙지 않는다 (시험으로 확인, 실제 기기 두 대로는 안 해 봄)
- [x] 설정 창 연결 방식 칸에 USB, 블루투스가 맞게 나온다
- [ ] 맥 블루투스를 끄면 설정 창에 이유가 나오고, 켜면 다시 붙는다
- [x] 윈도우용 컴파일 검사를 통과한다
