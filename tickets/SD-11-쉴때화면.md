# SD-11 [화면] 쉴 때 화면

| 종류 | 상태 | 우선순위 | 라벨 |
|---|---|---|---|
| 작업 | 진행 중 | 보통 | Android |

근거
- README 화면 원칙 "쉴 때는 검은 화면. 오래 쓰지 않으면 시계만 어둡게 남깁니다"
- 설계 1절 기능 목록의 AOD
- 설계 7절: 화면 안 꺼짐(안드로이드 됨, iOS 는 앱이 앞에 있을 때만), AOD 는 앱 안에서, 진동 세기 조절, 접는 폰
- 시안 목업(phonebox-mockup/v3 app.js 의 sleep, touch): 25초 손을 안 대면 시계만 남고, 누르면 돌아온다

## 목적

컴퓨터 옆에 세워 둔 폰이 꺼지지 않고 늘 시각을 보여 주게 한다. 그러면서 오래 손대지 않으면 검은 바탕에 어두운 시계만 남겨, 눈부심과 번인과 배터리를 줄인다.

## 범위

- 화면 켜 두기
  - 앱이 앞에 있는 동안 화면이 꺼지지 않게 한다(창에 화면 켜 둠 표시).
  - 앱이 뒤로 가면 표시가 풀리고, 폰의 화면 꺼짐 설정을 따른다.
  - 설정에서 "켜 두기"를 고른다: 늘, 충전 중일 때만, 안 함. 처음 값은 "충전 중일 때만"이다.
- 쉴 때 화면(검은 화면 시계)
  - 정해 둔 시간 동안 손을 대지 않으면, 지금 큰 화면이 무엇이든 검은 바탕에 어두운 시계만 남긴다. 처음 값은 5분이고, 고를 수 있는 값은 1분, 5분, 15분, 안 함이다.
  - 시계는 고른 모양 다섯 가지 모두를 쉬는 색(검은 바탕에 어두운 회색 한 색)으로 그린다. 해 동그라미와 작은 칸, 판 바탕은 그리지 않는다. 날씨 모양의 기온, 달력 모양의 날짜처럼 큰 글자도 어두운 회색이다.
  - 번인 막기: 시계 위치를 1분마다 몇 dp 씩 조금 옮긴다. 화면 가운데 둘레 안에서만 옮긴다.
  - 밝기: 앱 창 밝기를 낮춘다. 시스템 밝기 설정은 바꾸지 않는다.
  - 다시 누르면 쉬기 전 화면으로 돌아온다. 그 누르기는 버튼이나 칸에 전해지지 않고 깨우기만 한다. 뒤로 가기도 깨우기만 한다.
  - 쉬는 동안 상태 표시줄과 내비게이션 줄을 숨긴다(눈부심을 줄임). 깨면 되돌린다.
  - 쉴 때는 0.6초에 걸쳐 어두워지고, 깰 때는 0.2초에 밝아진다.
  - 고르기, 확인 창, 짝 맺기 화면, 시스템 권한 창이 떠 있는 동안은 쉬지 않는다.
- 쉬는 동안의 알림
  - AI 세션 알림(SD-7)이 오면 진동하고, 검은 화면 아래쪽에 4초 동안 제목과 상태를 어둡게 보인다. 진동은 한 번만 울린다.
  - 화면은 깨우지 않는다(README "저절로 넘어가지 않습니다"). 설정에서 "알림이 오면 깨우기"를 켤 수 있고, 처음 값은 끔이다. 켜도 30초 넘게 늦게 온 알림에는 깨우지 않는다(SD-7 의 늦은 알림 규칙).
- 진동 세기
  - 설정에서 진동을 고른다: 끔, 약하게, 보통, 강하게. 처음 값은 보통이다. 이 설정은 알림 진동과 버튼 누름 진동(단축키, 음악) 모두에 걸린다.
  - 진동 세기 조절이 되는 폰(진폭 조절 지원)에서만 세기를 바꾸고, 안 되는 폰은 켬과 끔만 쓴다.
- 설정 자리: 홈 고르기 줄(SD-4)에 "쉬기" 칩을 더해, 켜 두기, 쉴 때까지 시간, 알림에 깨우기, 진동을 고른다. 고른 값은 기기에 저장한다.
- iOS: 같은 규칙이다. 다만 화면 켜 두기는 앱이 앞에 있을 때만 된다(설계 7절). 진동 세기는 Core Haptics 로 한다. 이번 범위가 아니고 iOS 작업에서 만든다.

하지 않는 것
- 시스템 AOD(잠금 화면, 꺼진 화면 위 시계). 앱 안에서만 한다(설계 7절).
- 앱이 뒤로 간 뒤의 알림(알림 표시줄)
- 시스템 밝기, 화면 꺼짐 시간 같은 폰 설정 바꾸기
- 컴퓨터 쪽 바뀜(쉬는 동안의 구독 줄이기는 경계 상황에 적은 것만)

## 조치

- 화면 켜 두기는 창 표시(FLAG_KEEP_SCREEN_ON 이나 Compose 의 keepScreenOn)로 한다. WAKE_LOCK 권한은 쓰지 않는다.
- 충전 여부는 배터리 상태 알림(ACTION_BATTERY_CHANGED, 끈적 방송)으로 본다. 꽂고 뺄 때 켜 두기를 다시 정한다.
- 손 안 댐 시간은 화면 전체의 누르기와 밀기를 보는 한 곳에서 잰다. 고르기 중과 확인 창이 떠 있을 때는 쉬지 않는다.
- 쉴 때 화면은 ViewModel 상태 하나(쉼, 깨어 있음)로 두고, 화면 틀(DeskScreen) 위에 겹쳐 그린다. 화면 차례와 구독은 그대로 둔다.
- 번인 막기 위치는 시각에서 계산하는 순수 함수로 두어 시험한다.
- 접는 폰: 접고 펼 때 창 크기가 바뀌면 시계 위치와 크기를 다시 계산한다(SD-4 와 같음). 쉼 상태는 그대로 둔다.

## 경계 상황

| 상황 | 동작 |
|---|---|
| 배터리로 "늘 켜 두기" | 켜 두지만, 배터리가 15% 아래면 켜 두기를 풀고 폰 설정을 따른다 |
| 충전기를 뺌("충전 중일 때만") | 켜 두기를 풀어, 폰의 화면 꺼짐 시간이 지나면 꺼진다 |
| 폰이 절전 모드 | 켜 두기를 그대로 둔다. 쉴 때 화면은 그대로 검게 그린다 |
| 회사 관리(MDM)로 화면 꺼짐이 강제됨 | 폰 정책이 이긴다. 앱은 막지 않는다 |
| 쉬는 중 연결이 끊김 | 시계는 그대로 간다. 날씨는 흐리게(SD-4) |
| 쉬는 중 고르기나 확인 창 | 뜨지 않는다. 쉬기 전에 열려 있었으면 쉬지 않는다 |
| 접고 폄, 돌림 | 다시 계산하고 쉼 상태는 그대로 |
| 쉬는 중 앱이 뒤로 감 | 다시 오면 깨어 있는 화면으로 돌아온다 |
| 쉬는 동안의 구독 | 시계만 보이므로 날씨만 구독한다(AI 알림을 받으려면 Ai 도 tiles 에 둔다). 성능, 프로세스는 받지 않아 컴퓨터 수집이 쉰다 |
| 진동 세기를 못 바꾸는 폰 | 약하게, 보통, 강하게 모두 같은 진동이다. 설정에 "이 폰은 세기를 바꿀 수 없습니다"를 보인다 |

## 끝난 기준

- [ ] 앱을 앞에 띄워 두면 "켜 두기" 설정대로 화면이 꺼지지 않고, 충전기를 빼면 "충전 중일 때만"에서 풀린다
- [ ] 정해 둔 시간 동안 손을 대지 않으면 검은 바탕에 어두운 시계만 남고, 누르면 쉬기 전 화면으로 돌아온다
- [ ] 쉬는 동안 시계 위치가 조금씩 옮겨 간다
- [ ] 쉬는 동안 AI 알림이 오면 진동하고 어둡게 알리되, 화면은 깨우지 않는다(설정으로 깨우기 가능)
- [ ] 진동 세기를 고를 수 있고, 다시 켜도 남는다
- [ ] 접는 폰의 접은 화면, 펼친 화면, 바형 폰에서 쉴 때 화면이 겹치지 않는다(그림 시험)
- [ ] 쉬는 동안 컴퓨터의 성능, 프로세스 수집이 멈춘다
