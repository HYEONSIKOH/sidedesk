# SD-4 [홈] 시계와 날씨 화면

| 종류 | 상태 | 우선순위 | 라벨 |
|---|---|---|---|
| 작업 | 실제 기기 확인 남음 | 보통 | Core, Desktop, Android |

## 목적

기기를 세워 두었을 때 시계, 날짜, 날씨, 연결 상태를 한눈에 본다. 다른 기능은 옆의 작은 칸으로 함께 보인다.

## 범위

- 시계 모양 다섯 가지: 숫자, 바늘, 날씨, 달력, 모아 보기
- 테마 두 가지: 라이트, 다크. 시간에 따라 저절로 바꾸지 않는다
- 홈을 길게 누르면 시계 모양과 테마를 고른다. 이때 옆으로 밀면 모양이 바뀐다
- 날짜 옆 연결 아이콘: USB, 블루투스
- 날씨: 지금 기온과 하늘 상태, 최고와 최저 기온. 15분마다 새로 받는다
- 작은 칸: 지금 있는 기능(성능, 프로세스)만. 누르면 그 화면으로 넘어가고, 화면을 옆으로 밀어도 넘어간다
- 다른 화면을 볼 때 홈은 시각과 날씨만 보이는 작은 칸이 된다

하지 않는 것
- 일정과 알람
- AI 세션, 단축키, 음악 칸 (각 기능 정의서에서 칸까지 넣는다)
- iOS (설계 순서 6단계)

## 조치

- 시계 뒤에 동그라미를 두고 시각에 따라 위치를 옮긴다
- 시계는 기기의 시각으로 그린다. 컴퓨터와 끊겨도 계속 간다
- 날씨는 컴퓨터가 받아 기기로 보낸다. 설정 창 일반에서 날씨 제공처를 고른다(Open-Meteo, 기상청). 처음 값은 Open-Meteo 다
- 기상청을 고르면 공공데이터포털 인증키를 넣는 칸이 나온다. 키는 키체인(맥)에 두고, 설정 창에 다시 보이지 않는다(넣음 표시와 지우기만)
- 기상청을 골랐어도 키가 없거나, 위치가 국외거나, 받기가 실패하면 그 회차는 Open-Meteo 로 받는다
- 인증키는 저장소와 배포 묶음에 넣지 않는다
- 날씨 옆에 실제로 받은 곳의 출처를 보인다(기상청 또는 Open-Meteo)
- 위치는 기기의 대략적인 위치(소수 첫째 자리까지)를 컴퓨터로 보낸다. 위치 권한이 없으면 날씨를 받지 않는다
- 날씨 받는 곳은 포트 하나로 두고 기상청과 Open-Meteo 를 어댑터로 둔다
- 고른 시계 모양과 테마는 기기에 저장한다. 앱을 껐다 켜도 남는다
- 연결이 끊기면 연결 아이콘을 지우고, 날씨는 마지막 값을 흐리게 보인다
- 날씨를 한 번도 못 받았으면 기온 자리에 --° 를 보인다
- 접는 기기를 접거나 펼치면 배치를 다시 계산한다

## 끝난 기준

- [ ] 시계 모양 다섯 가지와 테마 두 가지를 고를 수 있고, 다시 켜도 남는다
- [ ] USB 와 블루투스에 맞는 아이콘이 나오고, 끊기면 사라진다
- [ ] 컴퓨터와 끊긴 동안에도 시계가 맞게 간다
- [ ] 위치 권한을 주면 날씨가 나오고, 주지 않으면 --° 가 나온다
- [ ] 설정 창에서 날씨 제공처를 고르고 기상청 키를 넣을 수 있다. 기상청이면 기상청, 키가 없거나 실패하면 Open-Meteo 로 받는다
- [ ] 접는 기기의 접은 화면, 펼친 화면, 바형 기기에서 글자와 칸이 겹치지 않는다
- [x] 윈도우용 컴파일 검사를 통과한다
