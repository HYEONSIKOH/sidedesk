# SD-6 [공통] 성능과 프로세스

| 종류 | 상태 | 우선순위 | 라벨 |
|---|---|---|---|
| 작업 | 진행 중 | 높음 | Core, Desktop, Android |

## 목적

폰에서 컴퓨터의 성능(CPU, GPU, 메모리, 디스크, 네트워크)과 많이 쓰는 프로그램을 보고, 프로그램을 끝낼 수 있게 한다. 화면 틀(왼쪽 큰 화면 + 오른쪽 작은 칸)도 이때 세운다.

## 범위

- 구독: 폰이 지금 보이는 것(큰 화면, 작은 칸)을 알리면 컴퓨터는 그것만 모아 보낸다. 아무도 안 보면 수집을 멈춘다
- 성능: CPU, GPU, 메모리, 디스크 사용률(%), 네트워크 받기/보내기 속도. 큰 화면일 때 1초, 작은 칸일 때 2초
- 프로세스: 많이 쓰는 프로그램 목록(이름, CPU %, 메모리), CPU 순과 메모리 순 정렬. 큰 화면 2초, 작은 칸 6초
- 프로세스 종료: 폰에서 한 번 더 확인하고, 컴퓨터는 프로세스 번호와 시작 시각이 모두 맞을 때만 끝낸다. 명령마다 번호를 붙여 두 번 실행하지 않는다
- 화면: 왼쪽 큰 화면(성능 또는 프로세스), 오른쪽 작은 칸(시계, CPU 등). 디자인은 docs/images 의 screens 그림을 따른다

하지 않는 것
- 홈 시계 화면의 날씨, AI 세션, 단축키, 음악, GitHub (다음 티켓)
- 윈도우 수집기 (컴파일만 통과)
- iOS 화면

## 조치

- 메시지 형식은 공용 코어 Protobuf 에 더한다. 버전이 다르면 모르는 값은 무시한다
- 맥 수집기는 desktop/mac, 구독과 보내기 규칙은 desktop/domain
- 안드로이드는 Jetpack Compose, MVVM

## 끝난 기준

- [ ] 폰에서 성능 화면을 열면 1초마다 값이 바뀐다
- [ ] 프로세스 화면에서 CPU 순, 메모리 순으로 바꿀 수 있다
- [ ] 프로세스를 끝내면 폰에서 한 번 더 묻고, 확인하면 컴퓨터에서 그 프로세스만 끝난다
- [ ] 폰 화면이 꺼지거나 앱이 뒤로 가면 컴퓨터 수집이 멈춘다
- [ ] 컴퓨터 프로그램 CPU 2% 아래, 메모리 60MB 아래 (설계 9절)
- [ ] 윈도우용 컴파일 검사를 통과한다
