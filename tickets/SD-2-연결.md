# SD-2 [공통] 연결

| 종류 | 상태 | 우선순위 | 라벨 |
|---|---|---|---|
| 작업 | 진행 중 | 높음 | Core, Desktop, Android |

## 목적

컴퓨터와 안드로이드 폰이 처음 한 번 짝을 맺고, 그다음부터는 저장한 키로만 암호화해서 붙게 한다. 케이블을 뺐다 꽂아도 알아서 다시 붙는다.

## 범위

- 짝 맺기: 양쪽에 같은 여섯 자리 숫자를 띄우고, 둘 다 맞다고 하면 서로의 공개 키를 저장한다
- 암호화 연결: 저장한 키가 아니면 끊는다
- 다시 붙기: 케이블을 빼면 폰은 마지막 값을 흐리게 보이고, 다시 꽂으면 알아서 붙는다
- 버전 확인: 큰 버전이 다르면 붙지 않고 업데이트하라고 알린다
- SD-1 의 암호화 없는 개발용 연결을 지운다

하지 않는 것
- iOS 연결 (설계 순서 6단계). iOS 앱은 "컴퓨터를 기다리는 중"으로 둔다
- 블루투스, 트레이와 설정 창, 짝 끊기 화면
- 컴퓨터 상태 수집 (컴퓨터 이름만 보낸다)

## 조치

- 암호화는 Noise XX(`snow`)로 하고 공용 코어에 한 번만 짠다. 컴퓨터와 폰이 같은 코드를 쓴다
- 짝 맺기 숫자는 연결마다 달라지고, 중간에서 가로채면 양쪽 숫자가 달라진다
- 컴퓨터는 adb 서버를 거쳐 폰 앱의 소켓에 접속한다. 컴퓨터에는 포트를 열지 않는다
- 컴퓨터 프로그램은 터미널 명령으로 쓴다. `sidedesk pair` 로 짝을 맺고 `sidedesk run` 으로 붙어 있는다

## 끝난 기준

- [x] 맥과 안드로이드 폰이 같은 숫자를 보고 짝을 맺는다
- [x] 짝을 맺은 뒤에는 숫자 없이 붙고, 폰에 컴퓨터 이름이 나온다
- [x] 케이블을 빼면 폰에 이름이 흐리게 남고, 다시 꽂으면 10초 안에 다시 붙는다
- [x] 짝을 맺지 않은 컴퓨터나 폰은 붙지 못하고 이유가 나온다
- [x] 큰 버전이 다르면 붙지 않고 이유가 나온다
- [x] 개발용 연결 코드가 남아 있지 않다
- [x] 윈도우용 컴파일 검사를 통과한다
