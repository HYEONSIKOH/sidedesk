# SD-7 [공통] AI 세션

| 종류 | 상태 | 우선순위 | 라벨 |
|---|---|---|---|
| 작업 | 실제 기기 확인 남음 | 높음 | Core, Desktop, Android |

## 목적

컴퓨터에서 돌리는 AI 코딩 작업(Claude Code, Codex)이 작업 중인지, 답을 기다리는지, 끝났는지를 폰에서 한눈에 본다. 끝나거나 답을 기다리면 폰이 진동하고 화면에 알린다. GitHub 와 GitLab 의 검토 요청, 내 요청, 알림 수도 같은 화면에 보인다.

## 범위

- 세션 목록: 맥에서 도는 Claude Code 와 Codex 세션. 세션마다 제목, 작업 폴더 이름, 상태(작업 중, 답변 대기, 끝남), 그 상태가 된 뒤 지난 시간
  - 제목은 사람이 붙인 이름, 없으면 자동 제목, 없으면 작업 폴더 이름
  - 작업 중과 답변 대기를 먼저(큰 카드), 그다음 최근에 끝난 것(작은 카드). 최대 12개
- 상태 판단: 컴퓨터에 남는 세션 기록 파일을 읽는다. 대화 내용은 읽어도 폰으로 보내지 않는다
  - 끝남: 마지막이 답이고 10초 넘게 새 기록이 없을 때(설계 9절, 의문점 5번)
  - 답변 대기: 도구 사용 허락이나 사람의 답을 기다릴 때
- 알림: 작업 중에서 끝남이나 답변 대기로 바뀌면 폰이 진동하고(끝남 한 번, 답변 대기 두 번) 4초 동안 알린다. 같은 바뀜은 한 번만
  - 알리는 곳: AI 작은 칸이 살짝 커지며 세션 제목과 바뀐 상태를 보이고, AI 가 큰 화면이면 그 세션 카드가 빛난다
  - 보고 있던 화면은 저절로 넘어가지 않는다(README 화면 원칙)
  - 30초 넘게 늦게 온 알림은 진동 없이 보이기만 한다
- GitHub, GitLab: 설치된 `gh`, `glab` 을 실행해 검토 요청, 내가 연 요청, 읽지 않은 알림 수를 3분마다 받는다. AI 큰 화면을 볼 때만
  - 프로그램이 없거나 로그인하지 않았으면 그 칸에 그 이유를 보인다
- 화면: AI 큰 화면(세션 카드, 아래에 GitHub/GitLab 고르기와 세 숫자), 작은 칸("AI n 작업 중", n 은 작업 중과 답변 대기 수). 디자인은 docs/images 의 screens 그림 첫 화면을 따른다
  - 화면 차례는 홈, AI, 성능, 프로세스다. 옆으로 밀거나 작은 칸을 누르면 넘어간다
  - 끊기면 마지막 목록과 숫자를 흐리게 둔다
- 구독: AI 가 큰 화면이나 작은 칸으로 보일 때만 세션 파일을 본다. 아무도 안 보면 멈춘다

하지 않는 것
- 폰에서 세션에 답하거나 세션을 멈추기
- 대화 내용, 명령, 파일 경로 전체를 폰에 보내기
- 끊긴 동안 생긴 알림을 다시 붙은 뒤 보내기(목록의 상태로 보인다)
- 다른 AI 도구, 윈도우 수집기(컴파일만 통과), iOS 화면

## 조치

- 메시지 형식은 공용 코어 Protobuf 에 더한다(세션 목록, 알림, GitHub/GitLab 수). 버전이 다르면 모르는 값은 무시한다
- 세션 기록 읽기는 새 크레이트 desktop/agents, `gh`, `glab` 실행은 desktop/forge(둘 다 운영체제를 모름), 상태 판단과 알림 규칙은 desktop/domain. 기록 모양이 바뀌어도 판단 규칙은 그대로 시험할 수 있게 나눈다
- 기록 파일은 바뀐 것만, 늘어난 끝부분만 읽는다
- `gh`, `glab` 은 정해진 인자로만 실행하고 결과의 숫자만 쓴다. 토큰을 읽거나 보내지 않는다
- 알림은 최신 값만 남기기 대상이 아니다. 연결된 동안 버리지 않는다(폰이 못 따라가 64개가 쌓이면 가장 오래된 것부터 버림)
- 안드로이드는 Jetpack Compose, MVVM

## 끝난 기준

- [ ] Claude Code 세션을 돌리면 폰에 작업 중으로 보이고, 끝나면 끝남으로 바뀌며 진동과 알림이 온다
- [ ] Claude Code 가 도구 허락을 물으면 답변 대기로 바뀌고 알림이 온다
- [ ] Codex 세션도 작업 중과 끝남이 보인다
- [ ] GitHub 검토 요청, 내 요청, 알림 수가 보이고, `glab` 이 로그인되지 않았으면 그 이유가 보인다
- [ ] AI 화면을 아무도 안 보면 컴퓨터가 세션 파일과 `gh`, `glab` 을 멈춘다
- [ ] 컴퓨터 프로그램 CPU 2% 아래, 메모리 60MB 아래를 지킨다(설계 9절)
- [ ] 윈도우용 컴파일 검사를 통과한다
