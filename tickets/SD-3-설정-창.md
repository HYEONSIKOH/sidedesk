# SD-3 [컴퓨터] 설정 창

| 종류 | 상태 | 우선순위 | 라벨 |
|---|---|---|---|
| 작업 | 진행 중 | 높음 | Desktop |

## 목적

컴퓨터 프로그램에 설정 창을 만든다. 터미널 없이 창에서 폰과 짝을 맺고, 짝 맺은 폰과 연결 상태를 본다. 이후 기능의 설정은 이 창에 칸을 하나씩 더한다.

## 범위

- `sidedesk` 를 실행하면 설정 창이 뜨고, 창이 열려 있는 동안 폰과 연결을 유지한다
- 폰 칸: 짝 맺은 폰 목록(기기 이름, 연결 상태), 짝 맺기(숫자 확인), 짝 끊기
- 정보 칸: 컴퓨터 이름, 버전, 이 컴퓨터의 키 지문
- 디자인은 크몽 포트폴리오 143541(관리자 대시보드)을 따른다. PhoneBox 설정 페이지의 모양은 따르지 않는다

하지 않는 것
- 페이지 배치, 단축키, 규칙, 웹훅, 고급 칸. 그 기능을 만들 때 칸을 더한다
- 트레이 아이콘, 창을 닫아도 뒤에서 도는 것, 설치 파일
- 윈도우에서 실제로 띄워 보기. 컴파일 검사까지만 한다

## 조치

- 화면은 HTML 로 짠다. 프로그램 안에 넣어 두고, 창 안의 웹 화면(WebView)으로 띄운다
- 컴퓨터에 포트를 열지 않는다. 화면과 프로그램은 창 내부 통로로만 주고받는다
- 터미널 명령 `sidedesk pair`, `sidedesk run` 은 그대로 둔다

## 끝난 기준

- [ ] `sidedesk` 를 실행하면 크몽 디자인의 설정 창이 뜬다
- [ ] 창에서 짝 맺기를 눌러 폰과 같은 숫자를 보고 짝을 맺는다
- [ ] 짝 맺은 폰이 목록에 나오고, 연결되면 초록, 끊기면 빨강으로 바뀐다
- [ ] 짝 끊기를 하면 그 폰은 다시 짝을 맺기 전까지 붙지 못한다
- [ ] 창을 띄워도 컴퓨터에 새로 열린 포트가 없다
- [ ] 윈도우용 컴파일 검사를 통과한다
